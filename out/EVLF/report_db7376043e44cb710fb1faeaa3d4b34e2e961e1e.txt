Analysis of the Tonto Team attack on Russian organizations in 2021
[]

In June 28, 2021, Group-IB Managed XDR detected a malicious spearphishing email. As you can see our solution quickly blocked the malicious email. Inside of this email was a malicious file, which we detected and have verdict - malicious: A malicious file from email attachment analysis report in our sandbox (Polygon): Initial vector The attacker uses mail as an initial vector of compromise. The file "30 июня в 17.30 - очередное заседание Исполкома АДЭ.doc" is attached to an email message. RoyalRoad RTF The analyzed file "30 июня в 17.30 - очередное заседание Исполкома АДЭ.doc" (this file is private, it's not uploaded on VT) is a malicious RTF document which was weaponized by Royal Road RTF Weaponizer. Royal Road is commonly used by Chinese-speaking attackers. The decoy is about the next meeting of the Executive Committee of the Documentary Telecommunications Association: Meta-information: The malicious encoded payload: Decoded payload - Bisonal.Dropper The decoded payload is a malicious PE32 format DLL file which can be classified as Bisonal.Dropper. This malware is used to deploy in a victim system a Bisonal backdoor. Compilation TimeDateStamp: 28.06.2021 01:44:01 UTC The Bisonal.Dropper creates a file "%AppData%\Roaming\conhost.exe" (Bisonal.DoubleT backdoor). It writes a random overlay data to "conhost.exe" to change the hash of a backdoor. The dropper also adds "conhost.exe" to a system startup by creating a registry key parameter: [HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Run] userInit = "%AppData%\Roaming\conhost.exe" The backdoor will only run after the system reboot. Also it can write to the log file "%windows%\temp\log.txt" following error messages: "[!] get pRegSetValueEx error\n" "[!] get pGetProcAddress error\n" "[!] get LoadLibraryA error\n" Bisonal.DoubleT variant "conhost.exe" is a malicious PE32 format EXE file which can be classified as a Bisonal.DoubleT backdoor. This malware provides remote access to a compromised computer and allows an attacker to execute various commands on it. Compilation TimeDateStamp: 24.06.2021 07:19:44 UTC Main functionality (capabilities): collect information about compromised host: code page layout, proxy server, time since system boot, host name, account name under which the file is running, local IP address; get a list of processes; terminate a specified process; get remote access to cmd.exe; download and execute file; get code page identifier and write file (create file on disk). The collected information about compromised host is encoded with Base32 algorithm.
