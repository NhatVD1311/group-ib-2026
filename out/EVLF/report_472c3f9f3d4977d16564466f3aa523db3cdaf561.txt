Template mechanism and search queries
[]

Old Version Previous Outisder version was loading the templates using a GET request: /api/open/getTemplateData/<template name>/a_index.html Additionally, the templates names have the following naming structure: <ISO code of the country that is being targeted>-<Template name/Targeted brand name> For example, for Serbia: Template Name Targeted Brand RS-Points-BancaIntesa Banca Intensa RS-POST-posta Posta Serbia For Spain: Template Name Targeted Brand ES-POST-correos Correos ES-BUZHU-endesa Endesa So, for searching for templates from previous version targeting an specific country, in this case, Spain, the following query can be used, depending on the platform: filename:"api/open/getTemplateData/ES-*" Current Version The new version loads the template name from a GET request that receives a JS file (common.js): HTTP GET request: /static/js/common.js Response: var cfg = { projectName: "AU-Points-Qantas3", errorJumpAddress: "hxxps://www[.]qantas[.]com/", loadinglayerStyles: "#d1331a", loadinglayerFont: "Loading, please do not close the page...", customPhoneDefaultValue: "your phone", customEmailDefaultValue: "Your email", isThankPage:"1" }; var cfg = { projectName: "JO-ticket-ammancity", errorJumpAddress: "hxxps://www[.]ammancity[.]gov[.]jo/", loadinglayerStyles: "#6d0b00", loadinglayerFont: "جاري التحقق، يرجى عدم مغادرة هذه الصفحة...", customPhoneDefaultValue: "هاتفك", customEmailDefaultValue: "بريدك الإلكتروني", isThankPage:"1" }; The template naming structure using the targeted country ISO code remains the same as before. The current searches can be used to get templates from certain queries, for Australia and Jordan, for example: body:{body:"var cfg =" AND body:"projectName:" AND body:"errorJumpAddress:" AND body:"loadinglayerStyles:" AND body:"loadinglayerFont" AND body:"customPhoneDefaultValue" AND body:"AU-"} body:{body:"var cfg =" AND body:"projectName:" AND body:"errorJumpAddress:" AND body:"loadinglayerStyles:" AND body:"loadinglayerFont" AND body:"customPhoneDefaultValue" AND body:"JO-"}
