Kit Capabilities — Attack Vectors 6.1. Real-Time Attack (Live Phishing) The core of the kit is full real-time control over the victim's screen via WebSocket (/ws). This allows bypassing any type of MFA. Screens the attacker can force (SCREEN_CHANGE): # Variable Screen shown to victim 1 FOLIO Case/claim number entry (complaint pretext) 2 VALIDANDO Animated loading screen with progress bar 3 LOGIN Banking username and password 4 CODIGO SMS code / MFA OTP 5 NIP ATM PIN 6 TARJETA Card number, expiration date, CVV 7 SMS_COMPRA Purchase authorization code (OTP for active transaction) 8 CANCELACION_RETIRO Cardless withdrawal code + withdrawal PIN 9 ESCANEAR_QR QR scan of physical card (session hijacking) 10 PROTECCION_BANCARIA Fake security alert inducing APK installation 11 PROTECCION_SALDO Captures debit and credit card balances 12 VERIFICACION_ID Activates camera to steal ID/Passport + Selfie (KYC bypass) 13 MENSAJE Free custom message 14 CANCELACION Cancellation/completion screen 6.2. Identity Theft — KYC Bypass The VERIFICACION_ID module activates the victim's device camera to capture: Front and back of national ID (INE) or Passport Victim selfie This data is used to bypass bank KYC systems: opening fraudulent accounts or authorizing high-risk transactions. 6.3. Malware Distribution (Not Confirmed) In the PROTECCION_BANCARIA state, the page displays a fake security alert ( "It is necessary to protect your balance" ) and induces the victim to install BankProtect.apk. The APK module allows the operator to: Upload a custom APK (/api/upload-apk) Assign it to specific users (/api/assign-apk) Serve it dynamically to victims via /api/get-user-apk/{id} 6.4. Multi-role (Fraudulent Call Center) The "Office" plan includes an Executive hierarchy where up to 8 sub-operators can simultaneously operate multiple victim sessions, replicating the structure of a fraudulent call center. 7. Operational Hierarchy SuperAdmin (balonx / brandon) └── Admin (affiliated operator — Individual or Office plan) └── Executive (Office plan sub-operator, max. 8) └── Victim session (real-time) Executives log in with an OTP sent via Telegram to the owning Admin. Executives can view and operate victim sessions in real time but do not have access to the full admin panel. The Admin controls which banks each Executive can use (allowedBanks). Each Admin can have up to 8 simultaneous Executives , replicating a fraudulent call center structure. 8. Link Generation and Management Generated links support Bitly shortening (bitlyLinkId, shortUrl fields in link_tokens table) Each link has an expiration time and can be extended in 30-minute blocks from the panel The link_usage_weekly table implements a weekly link quota per user , presumably as a service control mechanism The endpoint /api/generate-link?banco={BANK} generates a unique link per bank on each call 12. Evasion and Anti-Analysis Techniques Geolocation Spoofing: Overwrites navigator.geolocation to always return CDMX coordinates (19.4326, -99.1332), deceiving geographic anti-fraud systems. Headless Browser Evasion: Removes traces of Selenium, PhantomJS, and Nightmare from the browser environment. Canvas/WebGL Poisoning: Adds random noise to toDataURL and getImageData to alter browser fingerprinting. Human Behavior Detection (behaviorScore): Evaluates typing speed, mouse movement, and clicks. Threshold: 50 points. If the session does not appear human, access is blocked. WebRTC Spoofing: Injects fake STUN/TURN servers to hide the real C2 server IP. hCaptcha: Implemented as an anti-bot filter. The bundle uses the Vite test key (VITE_HCAPTCHA_SITE_KEY) instead of a production key — this may facilitate bypass in analysis environments. Device limit: Each operator account has a maximum of 2 registered devices (maxDevices). When exceeded, the user is redirected to /balonx to confuse investigators. 13.
